#OIBSIP
# 📝 Online Examination System

A Java Swing-based **Online Examination System** developed as part of the **Oasis Infobyte Java Development Internship**. This application simulates an online exam environment where users can securely log in, update their profiles, take a timed multiple-choice examination, navigate through questions, submit their responses, and instantly view their results.

The project demonstrates the implementation of Java Swing for GUI development, Object-Oriented Programming (OOP) concepts, event handling, and timer-based functionality.

---

## 🚀 Features

- 🔐 Secure Login System
- 👤 Profile Update Module
- 📝 Multiple Choice Questions (MCQs)
- ⏱️ Countdown Timer
- ⏮️ Previous & Next Question Navigation
- ✅ Manual Exam Submission
- 📊 Automatic Score Calculation
- 📋 Instant Result Display
- 🚪 Logout Functionality
- 🖥️ Interactive Java Swing User Interface

## 🛠️ Technologies Used

- Java Swing

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone https://github.com/Shivashakthi-source/OIBSIP.git
```

### 2. Navigate to the Project Folder

```bash
cd OIBSIP
```

### 3. Compile the Java Files

```bash
javac *.java
```

### 4. Run the Application

```bash
java Main
```

## 🎮 How to Use

1. Launch the application.
2. Enter the login credentials.
3. Update your profile if required.
4. Click **Start Exam**.
5. Read each question carefully.
6. Select the correct answer.
7. Use **Next** and **Previous** buttons to navigate.
8. Submit the exam before the timer expires.
9. View your score and exam result.
10. Logout after completing the examination.

## 📋 Modules

### 🔐 Login Module
- User authentication
- Validates login credentials
- Redirects to the examination dashboard

### 👤 Profile Module
- Update user information
- Save profile details

### 📝 Examination Module
- Displays multiple-choice questions
- Stores selected answers
- Supports question navigation

### ⏱️ Timer Module
- Countdown timer for the examination
- Automatically submits the exam when time expires

### 📊 Result Module
- Calculates total score
- Displays final marks
- Shows examination summary

### 🚪 Logout Module
- Ends the user session securely
- Returns to the login screen
