# Java Development Projects

This repository contains Java projects developed as part of my Java Development Internship at Oasis Infobyte.

The projects demonstrate core Java programming concepts, object-oriented programming, user interaction, GUI development, and application logic.

---

## Projects Included

### 1. Number Guessing Game

A Java-based number guessing game where the computer generates a random number and the player attempts to guess it.

#### Features

- Generates a random number between 1 and 100
- Allows the user to enter guesses
- Provides hints:
  - Too High
  - Too Low
  - Correct
- Tracks the number of attempts
- Includes a maximum attempt limit
- Displays the final result

#### Technologies Used

- Java
- Java Swing
- Object-Oriented Programming

#### Concepts Demonstrated

- Random number generation
- Conditional statements
- Loops
- User input handling
- Event handling
- GUI development

---

### 2. Online Examination System

A Java Swing-based online examination system that allows students to log in and attend a timed multiple-choice examination.

#### Features

- Student login system
- Student profile display
- Examination instructions
- Multiple-choice questions
- Previous and Next question navigation
- Answer selection and saving
- Countdown timer
- Automatic submission when time runs out
- Manual exam submission
- Automatic score calculation
- Result display
- Logout functionality

#### Technologies Used

- Java
- Java Swing
- Object-Oriented Programming

#### Concepts Demonstrated

- GUI application development
- Object-Oriented Programming
- Event handling
- ArrayList
- Timer implementation
- Question and answer management
- Navigation between application screens
- Score calculation
